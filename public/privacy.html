拼贴时光 / Collage Studio 隐私政策

更新日期：2026-10-16 · 生效日期：2026-10-16

本政策说明拼贴时光（Collage Studio，Android 应用标识 top.szlh.collage）如何在您创作拼贴时处理信息，以及您如何管理本机数据。下文中的“本应用”指 Android 原生应用；涉及网页版或外部服务时会另行说明。

核心说明：本应用免费、无广告，无需注册或登录。您选择的照片、视频、音频和编辑内容在本机处理；本应用没有素材上传、账户服务器、云同步或广告与行为分析功能。您可以离线编辑作品并阅读这份政策。

一、我们处理哪些信息，为什么处理

  • 您主动选择的文件：当您通过系统文件选择界面导入照片、视频、动画、背景音频或 .collage 项目备份时，本应用读取所选文件，以便在本机预览、裁切、排版、编辑、播放和导出。我们不会为此扫描您的整个相册或自动读取未选择的其他文件。
  • 作品及素材信息：为实现编辑和恢复草稿，本应用处理素材名称、文件类型、尺寸、时长，以及您输入的文字、作品标题、排版和其他编辑设置，并生成本机预览和缩略图。这些内容可能包含您或他人的个人信息，请仅导入您有权使用的素材。
  • 本机草稿：保存草稿时，本应用通过设备内的 IndexedDB 数据库存储作品编辑数据、原始素材、缩略图和更新时间，以便下次打开继续创作。它不是开发者服务器上的副本。

本应用不提供账户、登录、广告、用户行为统计或分析跟踪功能，不为这些目的收集身份、广告标识符或使用记录，也不将您的素材或作品上传给开发者。媒体处理、压缩和字体等依赖用于本机功能，不是向远程服务提交作品的功能。

二、本机处理、网络与系统文件访问

Android 正式安装包包含应用界面、示例图片、模板素材、贴纸及所需字体；这些资源从应用内加载，不需要向外部图片或字体服务发送您的素材。编辑、保存草稿和导出由本机完成，不依赖应用云端。

文件导入由您主动选择；导出使用系统保存界面，由您决定文件名和保存位置。本应用不要求为此授予整个存储空间或整个相册的广泛访问权限。若系统文件提供方允许您选择云盘或其他位置，该提供方的读取、保存与联网行为由您选择的服务及其设置决定。

本政策主要针对 Android 应用。访问网页版 https://collage.szlh.top 时，浏览器需要从网站加载页面和资源；这与 Android 安装包内置资源的方式不同，不表示本应用会上传您选择的文件。

三、导出、备份与您主动分享的内容

您可以导出作品文件，也可以导出用于恢复编辑的 .collage 项目备份。项目备份包含原始照片、视频或音频及编辑数据，不只是最终画面。原始素材及备份中的素材可能保留 EXIF 等元数据，包括原文件已有的拍摄时间、设备信息或位置等；本应用不承诺去除这些信息。

草稿和项目备份未由本应用另行加密。项目中的完整性校验用于检查文件内容，不是加密或访问保护。请妥善管理设备和备份，不要把不希望公开的原始素材或备份交给他人；分享前自行检查内容与元数据。

本应用不会自动对外分享作品。您在导出后使用其他应用分享，或将文件保存到第三方服务时，文件将按您的操作交给相应接收方，其后续处理适用该接收方的规则和隐私政策。

四、保留期限、删除与设备迁移

本机草稿用于供您继续编辑，没有应用设定的自动到期删除期限；通常会保留到您删除草稿、清除应用数据或卸载应用。系统清理、存储空间不足或设备故障也可能导致本机数据丢失，因此请自行保存重要项目备份。

  • 删除某份草稿：在“作品”中选择作品并确认删除，将删除该草稿在本应用数据库中的编辑数据、缩略图和素材副本，不会删除您在其他位置保存的原文件。
  • 清除全部本机应用数据：可通过 Android 系统设置中本应用的存储选项清除应用数据，或卸载本应用，以移除设备上的应用私有数据。具体入口以您的设备系统为准。网页版数据需在浏览器中清除该网站的存储，和 Android 应用数据分开管理。
  • 独立导出文件：已导出的图片、视频等作品文件和 .collage 备份独立于应用草稿存在；删除草稿、清除应用数据或卸载通常不会删除这些文件。请使用保存位置对应的文件管理器或服务单独删除，也请自行管理已分享给他人的副本。
  • 系统备份与迁移：若操作系统启用了系统级备份、恢复或设备迁移，相关应用数据可能由系统按其规则处理，受您的系统、账户及备份设置控制。这不属于本应用提供的云同步功能；系统或第三方服务中已有的副本需在相应设置或服务中管理。

本应用没有开发者持有的用户账户或云端作品库，因此不涉及应用账户注销，也无法替您找回已经清除、卸载或丢失且没有备份的本机作品。

五、外部链接与第三方服务

您主动点击官网、素材来源、项目反馈等外部 HTTPS 链接时，Android 应用会交由系统浏览器打开，不会在本应用的本机编辑界面加载远程网页。访问外部网站需要联网，该网站或您选择的浏览器如何处理信息，适用其各自的隐私政策。本应用不会随链接自动附带您的照片、草稿或项目备份。

六、未成年人和使用安全

未成年人应在监护人指导下使用本应用，避免在作品、文件名或公开反馈中披露本人或他人的住址、学校、联系方式等个人信息。本应用不设置儿童账户，也不通过广告或用户跟踪收集未成年人的信息。

本机处理不等于绝对安全。请保护设备访问权限、及时更新系统，并在对外分享前检查画面、音轨、原始文件及项目备份是否包含敏感内容。

七、隐私咨询、意见与政策更新

如对本政策、本机数据处理或删除方式有疑问，或需要报告隐私问题，请通过项目维护者的 GitHub Issues（隐私咨询与使用支持） 联系我们：
https://github.com/jeasoncc/collage-studio/issues。

GitHub Issues 是公开渠道，请不要上传私人照片、视频、音频、项目备份或含个人信息的截图，也不要公开填写联系方式等敏感信息。您可以先仅描述问题、应用版本和复现步骤；提交反馈时需遵守 GitHub 自身的使用规则与隐私政策，是否登录由 GitHub 决定，不是本应用的账户要求。

如果应用功能或信息处理方式变化，我们会相应更新政策并修改上方更新日期。您可随时从应用首页底部的“隐私政策”离线查看随当前版本附带的文本。
